# Sanitized Azure Scan Examples

Files under this directory are archived structural examples of Azure inventory output. Tenant, subscription, application, managed-identity, resource-generated, account, and hostname identifiers have been replaced with named placeholders such as:

- `{subscription-id}`
- `{tenant-id}`
- `{logic-app-client-id}`
- `{function-managed-identity-object-id}`
- `{unique-suffix}`

These files are **not runnable configuration** and are not current live evidence. Generate a fresh scan in your own tenant when validating a deployment. Do not commit unsanitized scan output, access tokens, keys, client secrets, user principal names, or complete resource IDs.

For current learner instructions, start with [START-HERE](../../START-HERE.md). For evidence refresh rules, see the repository's evidence-refresh instructions.
