Background: WAF and CAF Alignment

Optional best-practice reading, not required to complete Lab 3

Scope Note
This page maps the Lab 3 pattern to Microsoft architecture guidance. It is context material for design discussions, not a deployment checklist.

Well-Architected Alignment (High Level)

WAF Pillar Lab 3 Pattern Contribution Design Follow-up
Security Managed identity + Easy Auth + private connectivity reduces secret and exposure risks. Add policy guardrails and continuous security posture checks.
Reliability Identity and network controls are explicit and repeatable via IaC. Add zone/multi-region strategy based on business RTO and RPO targets.
Operational Excellence Standardized auth flow and validation scenarios improve runbook clarity. Add automated drift detection and production incident playbooks.
Performance Efficiency Direct service-to-service path avoids unnecessary gateway hops for core internal flows. Evaluate APIM if traffic shaping, caching, or policy centralization is needed.
Cost Optimization Passwordless auth removes operational secret rotation overhead. Track SKU choices and telemetry retention as workload grows.

Cloud Adoption Framework Context

  • Secure methodology: identity-first access and least privilege principles are directly applied.
  • Govern methodology: policy and standards can enforce consistent auth/network posture at scale.
  • Manage methodology: observable flows and scenario-based validation support day-2 operations.
